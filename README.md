# 가나다 — тренажёр корейского по TTMIK (уровни 1–9)

Обычный статический сайт: HTML + CSS + JS, без сервера и без сборки. Шрифты и иконки лежат внутри.

## Структура
- `index.html` — разметка
- `css/style.css` — стили (светлая и тёмная тема)
- `js/data.js` — уровни, слова и фразы (`урок|корейский|русский`)
- `js/extra.js` — глаголы для спряжения и диалоги
- `js/app.js` — логика
- `fonts/`, `icons/` — шрифты (лицензия SIL OFL) и иконки

## Запуск на компьютере
VS Code → расширение **Live Server** → правой кнопкой по `index.html` → **Open with Live Server**.

## Бесплатный хостинг
Голосовой ввод (микрофон) работает только по **https** или на localhost, поэтому выкладывайте на хостинг с https. Любой из вариантов бесплатный:

**Netlify Drop (проще всего, 1 минута):** откройте https://app.netlify.com/drop, перетащите папку `korean-trainer` в окно. Получите ссылку вида `https://что-то.netlify.app`. Чтобы сайт не удалился через час, зарегистрируйтесь (бесплатно) и привяжите его к аккаунту.

**GitHub Pages:** новый репозиторий на github.com → Upload files → перетащить содержимое папки → Settings → Pages → Branch `main`, `/ (root)` → Save. Адрес: `https://ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

**Cloudflare Pages:** dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets → загрузить папку.

Обновление: загрузите изменённые файлы заново тем же способом.

## Закрыто от поисковиков
Поисковикам запрещено индексировать сайт тремя способами: в `index.html` стоит `noindex`, `robots.txt` запрещает обход всем роботам, а `_headers` (Netlify и Cloudflare Pages) добавляет заголовок `X-Robots-Tag: noindex`. Добросовестные поисковики (Google, Яндекс, Bing) это соблюдают.
Это не пароль: любой, у кого есть ссылка, сможет открыть сайт. Если ссылка где-то опубликована, адрес теоретически может мелькнуть в поиске без содержимого. Чтобы такого не было, не выкладывайте ссылку в открытый доступ.

## Голосовой ввод
- Работает в **Chrome** и **Edge** (на компьютере и Android). В Firefox не поддерживается, в Safari работает нестабильно.
- Нужен интернет: распознавание речи браузер делает через свои серверы.
- При первом нажатии на 🎤 браузер спросит разрешение на микрофон, нужно разрешить.

## Где хранятся данные
Только в браузере (localStorage): ваши слова, прогресс, выбранные уроки, результаты тестов.
У каждого адреса сайта и каждого браузера свои данные. Перенос: «Уроки → Резервная копия».
